# Power BI Assignment 1 – E-Commerce Sales Analysis

## Overview

This project focuses on **data cleaning, transformation, grouping, and data modeling** using Power BI. The aim was to prepare e-commerce sales data for further analysis.

## Work Completed

* Imported **List of Orders, Order Details, and Sales Target** datasets.
* Cleaned and transformed the data using **Power Query**.
* Checked for missing and duplicate data.
* Created **Location, Profit Margin, and Profit Status** columns.
* Sorted and filtered the data.
* Grouped data to find order counts, average profit, total amount, and sales targets.
* Created relationships between the tables using **Order ID and Category**.

## Tools Used

* **Microsoft Power BI**
* **Power Query**

## Outcome

The data was successfully cleaned, organized, and modeled in Power BI, making it ready for further **sales analysis and visualization**.
